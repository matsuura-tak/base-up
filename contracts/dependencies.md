# 使ってよい依存ライブラリ

ここに書いたライブラリだけを使います。ここにないライブラリは足しません（要るときは報告に書き、tech-lead が判断して追加します）。
足すときは、公式のページと npm レジストリで存在・保守状況・`npm audit` 脆弱性 `0件` を確かめ、決めた理由を書きます。元に戻しにくいものは `docs/adr/` にも残します。
`package-lock.json`（`web/package-lock.json` および `web/tests/acceptance/package-lock.json`）は厳密固定（キャレット `^`・チルダ `~` なしの完全固定バージョン推奨）でコミットします。
reviewer は G2 で、差分の依存がこの表にあるかを確かめます。
