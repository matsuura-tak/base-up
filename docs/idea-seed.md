# 依頼内容
エンジニアの「論理的思考力・システム設計力・フェルミ推定力」を楽しくテスト＆強化できる、レトロアーケードゲーム風のブラウザゲームアプリを実装してください。

# コンセプトとアートディレクション（重要）
* 全体のタッチ・手触り：80〜90年代のレトロアーケードゲーム（ネオンカラー、ピクセル/ベクター風の軽快なグラフィック、スコアポップアップ、コンボ演出、Web Audio APIによるピコピコ系のチップチューン効果音、心地よい画面シェイクやゲージ演出）。
* 注意事項（NG要件）：パックマンのような「迷路ドットイートゲームそのもの（クローン）」にはしないでください。あくまで「思考パズルや数値推定を、レトロゲームのような直感的な画面アニメーションと手触りで遊べる」という表現・演出面でレトロゲーのテイストを取り入れてください。
* 退屈なテキスト問題集や電卓ツールに見えないよう、アクションを実行すると画面上のキャラクター・ユニット・オブジェクトが動き、視覚的に結果がシミュレーションされるゲーム画面（Canvas等）を中心に据えてください。

# ゲームのコアシステム（2つのゲームモード＋思考力カルテ）

## モード1：『3-ACT COMBINATOR』（3アクション・オブジェクト組み合わせパズル）
* 基本ルール：「ちょうど3回のアクション（STEP 1 → STEP 2 → STEP 3）」でステージごとの目的（ターゲット条件）を達成する。
* オブジェクト（ユニット／モジュール）の性能差：
  * 各ステージに5〜7個のユニークなオブジェクトが用意され、それぞれ「基本性能（増幅・変換・転送・範囲効果など）」「コスト（エネルギー消費／回復）」「副作用（発熱・ノイズ・他パラメータへの干渉）」「発動条件（if閾値分岐・シールド保護など）」を持つ。
  * どの3つを選び、どの順番で発動するかによって結果が劇的に変わる（非可換性・シナジー・リソース制約）。
* 難易度設計：ステージが進むにつれて単なる順序パズルから「副作用を逆利用する」「条件分岐の境界値を突く」「リソース枯渇や暴走上限（オーバーヒート等）をギリギリで制御する」など、エンジニアの設計思考を試す高難度ステージへ段階的にレベルアップする（最低8〜10ステージ実装し、すべてプログラム的に解が存在することを検証済みにすること）。
* ゲーム演出：「RUN（実行）」を押すと、1手目→2手目→3手目の挙動がレトロゲーム風のアニメーションと効果音で順番に再生され、失敗時は「どのステップで何が原因でクラッシュ／未達になったか」が視覚的にわかるデバッグログを表示する。

## モード2：『FERMI BLASTER / ESTIMATE QUEST』（フェルミ推定アーケードゲーム）
* 基本ルール：エンジニア面接やビジネス思考で重要な「フェルミ推定（未知の巨大な数値を論理的な因数分解と概算で導く力）」を、選択と組み合わせのレトロゲームに落とし込む。
* ゲームプレイの仕組み（自由記述ではなくゲームとして遊べる構造にすること）：
  * お題の例：「日本全国の稼働中自動販売機の1日の総売上は？」「東京都内で今この瞬間に開かれているWeb会議の総通信量は？」「1日に世界中で書かれるコード行数は？」など。
  * プレイヤーは**3ステップの分解スロット（例：ACT 1 [ベース母集団ユニット] × ACT 2 [絞り込み率・頻度フィルタ] × ACT 3 [単価・稼働補正ブースター]）**に対して、提示された複数の仮説カード／パラメータオブジェクトから妥当な組み合わせと概算値を選ぶ。
  * 選んだ数値とロジックに応じて、画面上のドット絵風ワールド／サーバー／都市オブジェクトが増殖・フィルタリングされるアニメーションが走り、最終推定値のレーザー／メーターが発射される。
* 判定とフィードバック：
  * フェルミ推定の本質に合わせ、ピンポイント一致ではなく「桁（オーダー）の一致度」と「分解ロジックの妥当性」でランク判定（PERFECT ORDER / GOOD RANGE / OVERKILL / UNDERESTIMATE）を行う。
  * 結果画面では「なぜその因数分解になるのか」「どの仮説カードが罠（二重計上や桁ズレ）だったのか」を端的に解説し、推定センスが鍛えられるようにする。
  * こちらも初級（2〜3要素の身近な推定）から上級（ボトルネック制約や供給側・需要側のクロスチェックが必要な推定）まで段階的に難易度が上がる複数ステージを用意する。

## 思考力診断カルテ（スコア＆レーダーチャート）
* 両モードのプレイ結果（クリア進捗、一発クリア率、試行回数、桁の精度、制約ミス回数など）から、プレイヤーのエンジニア思考特性を複数軸（例：仕様読解力・順序構築力・リソース制御力・フェルミ概算センス・仮説精度）で可視化し、アーケード風の認定ランク（S+〜C）を表示する。

# UI / 技術要件
* ブラウザ単体でそのまま動く完結した構成（外部サーバー不要、レスポンシブ対応、PC・スマホ両対応）。
* 効果音はWeb Audio APIによるシンセサイズ音で実装し、ミュート切り替えボタンを設けること（外部音声ファイル不使用）。
* すべてのボタン・モード切替・リセット・1ステップ検証が完全に動作し、未実装のダミー要素やプレースホルダーを残さないこと。
* 日本語UIで実装し、レトロゲームらしいワクワク感と、エンジニアが唸るロジカルな歯ごたえを両立させること。
