# 画面構造図（ワイヤーフレーム） 001-arcade-core

- 対象仕様：`design/001-arcade-core.md`
- 目的：全4画面における縦の整列基準線（B-3）、主操作1つの配置（B-2）、可視ラベルと第7章 UI 文言辞書の完全一致（WCAG 2.2 SC 2.5.3）、および PC 幅（`1280px`）からスマホ最小幅・文字拡大 `200%`（`320px` 相当リフロー）への折り返し規則（`AC-18`）を示す。
- 凡例：`[★ ... ]` ＝ 画面唯一のプライマリ主操作（`color.action.primary` 塗り）、`[ ... ]` ＝ セカンダリ／標準枠線操作（`color.border.default`）、`L0` / `L1` / `R0` ＝ 要素の端を揃える縦グリッド線。

---

## 共通シェルヘッダー（全画面上部 `<header>` + `<nav aria-label="モード切替">`）

```text
+--------------------------------------------------------------------------------------------------+
| [LOGIC ARCADE]  |  [3-ACT COMBINATOR]  [FERMI BLASTER]  [思考力診断カルテ]  | [SOUND（効果音）] SOUND ON  [JA][EN] |
+--------------------------------------------------------------------------------------------------+

```

### スマホ最小幅（`320px`）および文字拡大 `200%` リフロー
```text
|L0                        R0|  <- ビューポート320px（左右12px余白、有効幅296px、横はみ出し0px）
+----------------------------+
| [LOGIC ARCADE] [JA] [EN]   |  <- flex-wrap で折り返し（各ボタン >= 36x36px、最低 >= 24x24px）
| [SOUND（効果音）] SOUND ON |  <- 固定ラベルのトグルボタン + aria-describedby 状態バッジ
| [3-ACT COMBINATOR        ] |  <- 幅不足・200%拡大時は1列または折り返しリンク群（高さ >= 44px）
| [FERMI BLASTER           ] |
| [思考力診断カルテ        ] |
+----------------------------+
```

- 定義外 URL（例：`/unknown`）直アクセス時は、この共通ヘッダーの下の `<main id="main-content">` に `not-found-section`（`<h1> 指定されたページが見つかりません` ＋ 説明文 ＋ `[★ モード選択（トップ）へ戻る]`）を表示する。
