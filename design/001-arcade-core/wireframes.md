# 画面構造図（ワイヤーフレーム） 001-arcade-core

- 対象仕様：`design/001-arcade-core.md`
- 目的：全4画面における縦の整列基準線（B-3）、主操作1つの配置（B-2）、および PC 幅（`1280px`）からスマホ最小幅・文字拡大 `200%`（`320px` 相当リフロー）への折り返し規則（`AC-18`）を示す。
- 凡例：`[★ ... ]` ＝ 画面唯一のプライマリ主操作（`color.action.primary` 塗り）、`[ ... ]` ＝ セカンダリ／標準枠線操作（`color.border.default`）、`L0` / `L1` / `R0` ＝ 要素の端を揃える縦グリッド線。

---

## 共通シェルヘッダー（全4画面上部 `<header>` + `<nav>`）

### PC（`>= 768px` / `1280px`）
```text
|L0                                                                                      R0|
+------------------------------------------------------------------------------------------+
| [LOGIC ARCADE]   |  [3-ACT COMBINATOR]  [FERMI BLASTER]  [思考力診断カルテ]  | [♪ ON] [JA|EN] |
+------------------------------------------------------------------------------------------+
| (該当発生時のみ) [! ブラウザ保存が無効なため、このタブを閉じるまで履歴を保持します]        |
+------------------------------------------------------------------------------------------+
```

### スマホ最小幅（`320px`）および文字拡大 `200%` リフロー
```text
|L0                        R0|  <- ビューポート320px（左右12px余白、有効幅296px、横はみ出し0px）
+----------------------------+
| [LOGIC ARCADE] [♪ON][JA|EN]|  <- 1段目：flex-wrap で折り返し可能（各ボタン >= 24x24px）
| [3-ACT COMBINATOR        ] |  <- 2段目：幅不足・200%拡大時は1列または折り返しボタン群（高さ >= 44px）
| [FERMI BLASTER           ] |
| [思考力診断カルテ        ] |
+----------------------------+
```
